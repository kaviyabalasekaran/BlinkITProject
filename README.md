# BlinkITProject
Customer Shopping Behavior Analysis | Python, SQL, Power BI

Analyzed 3,900+ customer transactions to uncover spending patterns, loyalty trends, and subscription impact across multiple product categories.
Performed EDA in Python for data cleaning, feature engineering, and pattern discovery, and conducted SQL-based KPI analysis using CTEs and window functions.
Built an interactive Power BI dashboard with custom DAX measures to visualize revenue by age group, gender, and shipping type, along with discount and loyalty insights.
Delivered actionable findings showing that subscribers spent ~25% more, loyal customers drove majority revenue, and discounts had limited long-term ROI, guiding improvements in marketing and retention strategy.
